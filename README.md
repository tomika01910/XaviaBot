# 🤖 Sakib AI - Messenger Bot

**Sakib AI** is a smart, friendly Messenger bot that talks like a human friend, answers any question, and can even download videos when you ask it.  
It supports Banglish typing (Bangla in English letters) and works 24/7 non-stop!

---

## 🌟 Features

- 💬 Friendly human-like conversation  
- 🧠 AI-powered answers (like ChatGPT)  
- 📥 Video download from links  
- 🛠️ Command-based features  
- 🌐 Banglish language style (e.g., "Tumi kemon acho?")  
- ⚡ Hosted 24/7 on Railway  
- 🔐 Fully private and secure

---

## 🚀 Getting Started

### 1. Fork this Repo

Click the top-right `Fork` button to create your own copy.

### 2. Create `.env` File

Copy `.env.example` → rename it to `.env` and fill it with:

```
APPSTATE={"fb_dtsg": "...", "uid": "...", ...}
BOT_NAME=SakibAI
PREFIX=.
LANG_STYLE=banglish
DOWNLOAD_VIDEO=true
```

> Don't have `APPSTATE`? Ask Sakib for help generating session.

### 3. Deploy to Railway

- Go to [https://railway.app](https://railway.app)  
- Login with GitHub  
- Create new project from your forked repo  
- Add all `.env` variables  
- Click **Deploy**

## 💬 Example Commands
